しばコレ ARラボ — 独立したテスト用アプリ

1. index.html を HTTPS のWebサーバー（GitHub Pagesなど）に配置します。
2. GLBファイルは models/ フォルダに入れてください。選択肢のファイル名が異なる場合、index.html の option value を実際の名前に変更してください。
3. スマホでサイトを開き、「カメラを起動」を押して権限を許可します。
4. 画面上で3Dモデルを選び、距離・サイズ・高さを調整できます。
5. GLBファイルを直接選ぶこともできます。この場合は配置不要です。

注意: これはGPS不要のカメラ合成テストであり、平面検出やワールドアンカーを使用する本格WebXR ARではありません。モデルはカメラの正面に固定表示されます。モデル配置は実機未検証です。
